# 1. The `ConversationStore` port, with OpenAI Conversations as the default

- **Status:** ready
- **Release:** 0.6 (base branch `release/0.6`)
- **Lane:** Core
- **Touches hot files:** Yes (`gateway.ts`, `server/handler.ts`, `openai/history.ts`; the API snapshot is regenerated)
- **Changes the public API or the protocol:** Yes: API snapshot and a minor changeset (ADR-0006 is updated by z1)
- **Depends on:** none

## Goal

Conversations go through a public `ConversationStore` port. `openaiConversations()` is the default and behaves exactly as 0.5 does; `memoryConversations()` exists for tests; the contract suites ship, so the Postgres add-on (a2) and third parties can build stores against them. This is the first step on 0.6's critical path, so keep it to the port and the move.

- [ADR-0024](../docs/adr/0024-conversation-store.md) (Proposed), decisions 1, 2, 5, 10, 12 and 13. ADR-0003, ADR-0004, ADR-0006, ADR-0022 (settled answers are notes in the conversation).
- `spikes/s7-store/`: `port.ts`, `memory-store.ts`, `openai-store.ts`, `contract.ts` and `FINDINGS.md`. Start from them; they ran 31 of 31 contract tests.

## Files and area

- New `packages/askdare/src/conversations/`: the port and its item types (no `openai` types), `memoryConversations()`, and the contract suite.
- `openaiConversations()` in `src/openai/`: today's `createConversation`, `listMessages`, `deleteConversation` and `settleAnswer` move out of `ModelGateway` (`gateway.ts`, `openai/gateway.ts`, `openai/history.ts`, `openai/guardrails.ts`) onto it. Its `context()` returns a provider reference; `append()` writes the items askdare writes today (guardrail notes, `suggest_replies` outputs, repair outputs).
- `server/handler.ts` and `next/create-chat-handler.ts`: a `conversations` option, defaulting to `openaiConversations()`. The server checks `info()`'s bot and owner against the resume token's claims and answers a mismatch exactly like an unknown conversation. For OpenAI this replaces the metadata check, with the same behaviour.
- `memoryConversations()` is an item store. Until task 2 lands, `createChatHandler` refuses an item store at startup with a clear error ("needs stateless turns"), so `release/0.6` never runs a half-built mode.
- New subpath `@boldare/askdare/testing`: `conversationStoreContract` and `rateLimitStoreContract` (move it from `limits/store-contract.ts`; switch `packages/askdare-upstash`'s test to the subpath). The suites take `describe`, `it` and `expect` as arguments and delete what they create, also after a failure. Add the subpath to `package.json` `exports`, `tsdown`, publint and attw.
- Rename while it is internal: `ConversationMetadata.visitorId` becomes the `owner` string of ADR-0024.
- Docs: `docs/custom-store.md` gains the conversation store; `docs/configuration.md` the option.

## Don't touch

- `openai/turn.ts` and `server/stream-turn.ts` beyond what the move needs: stateless turns are task 2.
- `packages/askdare-postgres/` (a1, a2), `src/knowledge/` (k1).
- ADR-0006 (z1). If the port must differ from ADR-0024, amend the Proposed ADR in this PR.
