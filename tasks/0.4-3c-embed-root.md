# 3c. `EmbedRoot`: your own page in the widget's iframe, with the demo and the docs

- **Status:** ready
- **Release:** 0.4
- **Lane:** Core
- **Touches hot files:** Yes (`react/headless.ts` if the embed context lives there, the API snapshot and ADR-0006)
- **Changes the public API or the protocol:** Yes: a new package entry, API snapshot, ADR-0006 and a minor changeset
- **Depends on:** none (3b is done)

## Goal

A site serves its own page in the widget's iframe with `EmbedRoot`: the visitor on any embedding site sees the site's look and its tool cards, and the page talks to the loader exactly as the library's iframe does.

## Decisions to read first

ADR-0018 (the whole of "The page at `embedPath`" and "Risks"), ADR-0005 (the handshake), ADR-0011, ADR-0014 (language switches), ADR-0017

## Files and area

- A new entry `packages/askdare/src/embed-root/` (name it as the package's layout suggests), exported as `@boldare/askdare/embed`: `EmbedRoot`, reusing `widget-app/host-bridge.ts`, `bind-bridge.ts` and `switch-locale.ts` rather than copying them. Move them to a shared place if the build needs it.
- `DefaultChat` inside `EmbedRoot`: owns the document (`h1`, modal confirm, Escape anywhere) and shows the close button outside `inline` mode, through a small context; check `react.js` stays within its budget (`scripts/react-size.mjs`).
- Packaging: a tsdown block with the `'use client'` banner, `exports["./embed"]`, a size budget for the entry, the no-leak check, `attw`, the API snapshot, a consumer in `types-test`, and `verify-packs` building a page with it.
- `site/`: a demo bot with `embedPath` and its page in its own route group and root layout, with `embedPageHeaders` in `next.config.ts` and the site's `toolRenderers`.
- `e2e/`: on the host page of another origin, the widget for that bot opens the site's page, shows a tool card, follows `askdare('identify')`, `configure`, `on` and a language switch, closes from its button, and refuses to be framed by an origin outside the allowlist.
- Docs: `docs/embedding.md` (a section on your own page: route group, headers, proxy `matcher`, no third-party scripts), `docs/react.md` (`EmbedRoot`), `THREAT_MODEL.md` (a row for the iframe page in the app), the READMEs' links, the `askdare` skill and `llms.txt`.

## Don't touch

- `embed/loader.ts`: unchanged, as ADR-0018 decides.
- The library's iframe page and its visual baselines: they must not change.
- `examples/starter/`: `embedPath` is opt-in, not part of the minimal template.

## Definition of Done

- [ ] Unit tests: `EmbedRoot` joins the bridge only from the parent and an allowed origin, replays identity and `configure`, emits events, follows a language switch, works opened directly; `DefaultChat` inside it owns the document; under React and Preact for the shared bridge
- [ ] e2e in Chromium, Firefox and WebKit as above; the library's iframe baselines unchanged
- [ ] `@boldare/askdare/embed` within its budget, `react.js` within its own
- [ ] Docs updated
- [ ] Changeset (minor)
- [ ] `pnpm check` passes
