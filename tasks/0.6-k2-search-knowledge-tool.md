# k2. Knowledge from an index: the `search_knowledge` tool

- **Status:** blocked (2, k1, h1)
- **Release:** 0.6 (base branch `release/0.6`)
- **Lane:** Core
- **Touches hot files:** Yes (`bot/define-bot.ts`, `openai/turn.ts`, `openai/history.ts`; the API snapshot is regenerated)
- **Changes the public API or the protocol:** Yes: API snapshot and a minor changeset (ADR-0006 is updated by z1). No protocol change
- **Depends on:** 2, k1, h1 (h1 lands on `main`; merge `main` into `release/0.6` first)

## Goal

A bot with `knowledge: { index }` answers from its own index through a `search_knowledge` tool, with citations the visitor can't tell from `file_search`'s, after a reload too. Bots with `vectorStoreId` behave as before.

## Decisions to read first

- [ADR-0025](../docs/adr/0025-knowledge-index.md) (Proposed), decisions 2, 3, 5, 6, 9 and 12; ADR-0019 (the untrusted wrapper), ADR-0015 (reserved tool names), ADR-0004.
- `spikes/s8-retrieval/`: `citations.ts` (`MarkerRewriter`, `RETRIEVAL_RULES`), `eval.ts`, `questions.json` and `FINDINGS.md`.
- The `openai-api` skill.

## Files and area

- `bot/define-bot.ts`: `knowledge: { index, maxResults? }` as an alternative to `vectorStoreId`, validated so a bot has one or the other; `search_knowledge` reserved.
- `openai/tools.ts` and `openai/turn.ts`: the strict `search_knowledge` tool with one `query` argument, under the bot's step limits. Its output is always wrapped as untrusted (ADR-0019), and the retrieval rule joins the instructions. A `tool.status` for knowledge, as `file_search` has.
- `openai/citations.ts` and `openai/stream-mapper.ts`: rewrite `[id]` markers to `[n]` while streaming and emit `citation` events, resolving IDs through the turn's results first and `passage()` after; unknown IDs are dropped and counted (no content in logs).
- History: item stores store citations on the text part; `openaiConversations()` rewrites stored markers through `passage()` on reload.
- `openai/diagnose.ts` and `doctor`: the checks `knowledge.pgvector`, `knowledge.synced`, `knowledge.embedder`, through the index's `diagnose()`.
- Exports: the knowledge port types and `openaiEmbedder` from `@boldare/askdare`, `knowledgeIndexContract` from `@boldare/askdare/testing`.
- Accepting ADR-0025 needs one more piece of evidence: rerun S8's evaluation (in `spikes/s8-retrieval/`, against this code path or a copy of it) with 12-character source IDs and a few multi-turn follow-ups that cite a passage from an earlier turn. Record the result in the ADR's Evidence section, or amend the ADR.
- Docs: `docs/knowledge-base.md` (both paths), `docs/tools.md` (the reserved name).

## Don't touch

- `cli/kb-sync.ts` (k3), `packages/askdare-postgres/` (a3), history paging (3a).

- [ ] S8's evaluation rerun and recorded in ADR-0025
