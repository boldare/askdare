# a1. The `@boldare/askdare-postgres` package

- **Status:** ready
- **Release:** 0.6 (base branch `release/0.6`)
- **Lane:** Add-ons
- **Touches hot files:** No
- **Changes the public API or the protocol:** Yes: a new package (its own changeset); no change to `@boldare/askdare`
- **Depends on:** none

## Goal

An empty but releasable `@boldare/askdare-postgres` exists, with its schema machinery and a CI job against Postgres with pgvector, so a2 (conversations) and a3 (pgvector) can each fill their own folder at the same time.

## Decisions to read first

- [ADR-0024](../docs/adr/0024-conversation-store.md) (Proposed), decisions 2 and 9; [ADR-0025](../docs/adr/0025-knowledge-index.md), decision 3; ADR-0001 (packaging), ADR-0006, ADR-0007 (tooling).
- `packages/askdare-upstash/` as the model for an add-on: `package.json`, `tsdown.config.ts`, README, changeset, how CI and `pnpm check` include it.
- `spikes/s7-store/schema.sql`, `spikes/s8-retrieval/pg-index.ts` (its DDL), and both spikes' `docker-compose.yml`.

## Files and area

- `packages/askdare-postgres/`: `package.json` (`pg` as the only dependency, `@boldare/askdare` as a peer), tsdown, tsconfig, README, `CHANGELOG.md` through Changesets, an initial changeset.
- `src/schema/`: the schema as code (no `.sql` files read at runtime), numbered migrations, a schema-version table, `migrate({ url | pool })` and a bin `askdare-postgres migrate` reading `DATABASE_URL`. It never runs at request time. Leave the migrations themselves empty: a2 and a3 add theirs.
- `src/index.ts` with the shared connection options (a `url` or an existing `pg.Pool`). a2 and a3 each add one export line.
- CI (`.github/workflows/ci.yml`): a Postgres 17 service with pgvector for this package's tests, and the package in `pnpm check:packages` (publint, attw, no-leak). A local `docker-compose.yml` for contributors.
- Root files the package needs (`pnpm-workspace.yaml`, `.changeset/config.json`, `.gitignore`, `verify-packs`).

## Don't touch

- `packages/askdare/` (task 1 creates `@boldare/askdare/testing`; the stores import the contract suites from there later).
- `src/conversations/` and `src/knowledge/` inside the new package (a2, a3).

## Definition of Done

- [ ] `migrate` creates and upgrades the schema-version table idempotently, tested against the CI service
- [ ] The package builds, passes publint, attw and no-leak, and is part of `pnpm check`
- [ ] README with install and `migrate`; changeset
- [ ] `pnpm check` passes
