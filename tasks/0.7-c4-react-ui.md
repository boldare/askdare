# c4. Handoff and forms in the widget and the React API

- **Status:** in progress
- **Release:** 0.7 (base branch `release/0.7`)
- **Lane:** Core
- **Touches hot files:** Yes (`react/headless.ts`, `i18n/texts.ts` and `i18n/locales/*`)
- **Changes the public API or the protocol:** Yes: API snapshot and a minor changeset
- **Depends on:** c3

## Goal

Visitors see a "connecting you" state and fill in forms in the default widget and in the inline chat, accessibly (WCAG 2.2 AA), in every built-in language; headless users get the same through `useChat` and primitives.

## Decisions to read first

- ADR-0030, ADR-0031, [ADR-0011](../docs/adr/0011-react-api-and-inline-chat.md), [ADR-0017](../docs/adr/0017-tool-renderers.md), [ADR-0014](../docs/adr/0014-runtime-language.md), [ADR-0028](../docs/adr/0028-react-budget-34-kb.md).
- `docs/accessibility.md` (the conformance statement this must keep true).
- The `vercel-composition-patterns` skill.

## Files and area

- `react/headless.ts` and new primitives (a form card with labelled fields, errors announced, focus moved on error).
- `react/skin/*` and `react/skin/askdare.css`: the default look; the iframe app in `widget-app/`.
- `i18n/texts.ts` and every file in `i18n/locales/`: the new texts in English, Polish, Czech, German, Spanish, French and Italian.
- Also add the texts l2 needs for the greeting and the badge (ADR-0033), so l2 doesn't touch `texts.ts` again.

## Don't touch

- `embed/loader.ts` (l1, l2), `server/*`.
