# 1b. `GET <basePath>/config/<bot>?lang=`

- **Status:** blocked
- **Release:** 0.4
- **Lane:** Core
- **Touches hot files:** Yes (`docs/protocol.md`)
- **Changes the public API or the protocol:** Yes: protocol, additive within v1
- **Depends on:** 1a

## Goal

The chat can fetch its public configuration for another language without reloading the iframe.

## Decisions to read first

ADR-0014 (Step 2), ADR-0004, ADR-0008, `docs/protocol.md`

## Files and area

- `packages/askdare/src/server/handler.ts`: a GET route in `route()`, next to `serveTheme`.
- The route reuses `publicConfig()`, the function the embed page and `getChatConfig` use, so the "no secrets" test covers it.
- Request rules:
  - `lang` is canonicalized;
  - a bot with a fixed locale ignores `lang`;
  - an unknown bot or an invalid tag gets the existing error codes.
- Short `Cache-Control`. The language is in the URL, so no `Vary` is needed.
- `docs/protocol.md`: the new endpoint, additive within protocol v1.

## Don't touch

The store, the bridge and React (1c).
