# 2. Stateless turns from an item store

- **Status:** blocked (1)
- **Release:** 0.6 (base branch `release/0.6`)
- **Lane:** Core
- **Touches hot files:** Yes (`openai/turn.ts`, `server/stream-turn.ts`, `gateway.ts`)

- **Depends on:** 1

## Goal

With an item store (`memoryConversations()` now, Postgres after a2), a turn replays the stored history with `store: false` and leaves nothing of the conversation at OpenAI. Cost, caching and recall match conversation mode, as S7 measured.

## Decisions to read first

- [ADR-0024](../docs/adr/0024-conversation-store.md) (Proposed), decisions 3, 4, 8 and 11; ADR-0022 (notes, one turn at a time); ADR-0003's S1 evidence (dangling calls).
- `spikes/s7-store/`: `turn.ts` (both modes), `openai-map.ts`, probes p1 to p3 in `FINDINGS.md`.
- The `openai-api` skill. Check in the `openaiDeveloperDocs` MCP server how reasoning items replay with `store: false` today (S7: encrypted reasoning comes back by default; the reasoning guide, "Preserve reasoning without stored responses").

## Files and area

- `src/openai/`: a mapper between stored items and Responses input and output items (from S7's `openai-map.ts`), deterministic, so the same item always gives the same JSON. Reasoning goes in as `native` items tagged with the model family and is replayed only to that family.
- `openai/turn.ts`: with an item context, send `store: false`, no `conversation` and no `truncation`; append in S7's order (visitor message with `expect` before the first call; each step's items and its call outputs in one append; `suggest_replies` outputs with the last step). A version conflict ends the turn with `rate_limited`.
- `server/stream-turn.ts` and `openai/guardrails.ts`: settled-answer notes and replacements are appended to the item store (ADR-0022's rules unchanged). For item stores, the feedback handle is the stored item's ID, not OpenAI's.
- History from an item store: a provider-neutral reader from stored items to `HistoryMessage`, with replies and UI payloads from the stored calls (`RepliesReader`, `UiReader`), and citations from the text part.
- Remove task 1's startup refusal of item stores.
- `docs/privacy.md`: what stays at OpenAI with an own store (files, and the 30-day abuse-monitoring retention of requests) and that ZDR organisations can use it. `docs/costs.md`: larger requests, same cost.

## Don't touch

- History paging (3a), `search_knowledge` (k2), the Postgres package (a2).
- Compaction and any `maxItems` window option: spike S9 decides.
