# D1. Starter template repo for a one-click Heroku button

- **Status:** blocked (the maintainer approves creating the repository)
- **Release:** 0.4
- **Lane:** Deploy
- **Touches hot files:** No
- **Changes the public API or the protocol:** No
- **Depends on:** the maintainer's approval

## Goal

The Heroku button needs `app.json` at a repository's root. A true one-click Heroku deploy therefore needs the starter in its own repository: `boldare/askdare-starter`, a template repository mirrored from `examples/starter` by CI.

## Decisions to read first

`docs/deployment.md` and `CLAUDE.md` (the starter rules)

## Files and area

- The new repository, created only with the maintainer's approval.
- A CI job that mirrors `examples/starter` on each release.
- The Heroku button in the READMEs and the docs.

## Don't touch

`packages/`

## Definition of Done

- [ ] The maintainer approved creating the repository
- [ ] The mirror job keeps it in sync on every release
- [ ] The Heroku and Vercel buttons point at it
- [ ] `pnpm check` passes
