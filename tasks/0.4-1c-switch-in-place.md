# 1c. Switch the language in place

- **Status:** blocked
- **Release:** 0.4
- **Lane:** Core
- **Touches hot files:** Yes (`chat/store.ts`, possibly `react/headless.ts` and `embed/loader.ts`)
- **Changes the public API or the protocol:** Yes: API snapshot, ADR-0006 and a minor changeset
- **Depends on:** 1b

## Goal

Switching the language keeps the chat on screen: the iframe doesn't reload, and the messages, the draft and an answer in progress stay. Step 1's reload remains only for a chat that hasn't connected yet.

## Decisions to read first

ADR-0014, ADR-0005, ADR-0011, ADR-0013

## Files and area

- `packages/askdare/src/chat/store.ts`: `setLocale(locale)` fetches `/config/<bot>?lang=` (1b), swaps the texts and the locale, and keeps the state.
- `packages/askdare/src/chat/chat-client.ts`: the locale becomes mutable, and the next message carries the new one.
- `packages/askdare/src/widget-app/host-bridge.ts` and `widget-app/app.tsx`: the existing `locale` port message calls `setLocale` instead of reloading.
- `packages/askdare/src/embed/loader.ts`: only if needed. It is at 4,963 of its 5,120 bytes.
- `packages/askdare/src/react/root.tsx`: stop keying the store by locale, and call `setLocale` when `config.widget.locale` changes.
- No new chat event unless ADR-0013 needs one.

## Don't touch

`defineBot` (1a) and the handler (1b).

## Definition of Done

- [ ] Unit tests for `setLocale`:

  - inline `Root` keeps its messages when the locale prop changes.
