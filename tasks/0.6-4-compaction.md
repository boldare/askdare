# 4. Compaction for conversations in our own store

- **Status:** blocked (2, k2, t1)
- **Release:** 0.6 (base branch `release/0.6`)
- **Lane:** Core
- **Touches hot files:** Yes (`bot/define-bot.ts`, `openai/turn.ts`, `server/stream-turn.ts`; the API snapshot is regenerated)
- **Changes the public API or the protocol:** Yes: `limits.compactAt` and an optional compaction entry in the `onUsage` report; API snapshot and a minor changeset (ADR-0006 is updated by z1). No protocol change
- **Depends on:** 2 (stateless turns), k2 and t1 (they share `openai/turn.ts`, `bot/define-bot.ts` and `server/stream-turn.ts`)

## Goal

A bot on an item store (memory or Postgres) can set `limits.compactAt`. Once a turn's input reaches it, askdare compacts the conversation after the turn, in the background, and the next turns replay a few thousand tokens instead of the whole history. Facts and citations stay. Bots on `openaiConversations()`, and bots without `compactAt`, behave as before.

## Decisions to read first

- [ADR-0029](../docs/adr/0029-compaction-for-item-stores.md) (Proposed): all of it.
- [ADR-0024](../docs/adr/0024-conversation-store.md), decision 3 (append-only, `expect`, the `maxItems` window); ADR-0003's S5 and S5b updates (why `openaiConversations()` gets none); ADR-0012 (`onUsage`); ADR-0022 (the turn lock).
- `spikes/s9-compaction/`: `FINDINGS.md`, `probe-trigger.ts` (the request), `items.ts` (`window()`, `native` with a kind), `growth.ts` with `S9_THRESHOLD` (the saw-tooth and the rising floor).
- The `openai-api` skill. Check the compaction guide in the `openaiDeveloperDocs` MCP server first: `compaction_trigger` and its `max_output_tokens` minimum (20,000 on 2026-11-23, not in the guide).

## Files and area

- `bot/define-bot.ts`:
  - `limits.compactAt`, an integer between 20,000 and 272,000, unset by default;
  - a startup warning when it is set with `openaiConversations()`, where it does nothing.
- The store's item types (task 1):
  - a kind tag on `native` items, so `context()` can start the window at the latest compaction item of the current model family without parsing provider JSON;
  - the contract suite tests that window, the fallback when the model family changes, and that history and paging skip compaction items.
- `src/openai/`, a `compact(window)` on the gateway:
  - one `responses.create` with the replayed window plus `{ type: 'compaction_trigger' }`;
  - the bot's model, instructions, tools and `prompt_cache_key`;
  - `store: false`, `max_output_tokens: 20000`, the turn's `safety_identifier`, an explicit timeout and an `AbortSignal`;
  - it returns the compaction item mapped to a `native` item, and its usage.
- `server/stream-turn.ts`:
  - when the last step's `usage.input_tokens` reached `compactAt` and the store returns items, run the compaction in `waitUntil` after the turn lock is released;
  - append it with `expect`; a `VersionConflict` drops it quietly;
  - skip it when the guard of ADR-0029 decision 7 applies.
- `limits/limits.ts`: reserve an estimate for the compaction (not 20,000 output tokens), and settle its real usage against the same budgets.
- The `onUsage` report: an optional compaction entry (usage, duration, outcome), kept apart from the turn's `usage`.
- Docs:
  - `docs/costs.md`: what `compactAt` saves and costs, with S9's numbers;
  - `docs/limits` (or where limits are documented): `compactAt`, and the note that the compaction item is opaque and its quality is OpenAI's;
  - `docs/privacy.md`: the compaction item is stored with the conversation and deleted with it.

## Don't touch

- `openaiConversations()`: no compaction there (ADR-0003, S5b).
- Fallbacks for other providers (elided search results, own summary): ADR-0029 decision 8, decided with the provider path.
- How budgets weight cached tokens: a separate task if the maintainer takes S9's suggestion.

## Definition of Done

- [ ] Unit tests: the window starts at the latest compaction item of the model family; another family replays everything; a conflict drops the compaction; the floor guard; nothing happens without `compactAt` or with `openaiConversations()`
- [ ] A recorded `compaction_trigger` response (redacted: encrypted content and IDs replaced) replayed in a turn test
- [ ] The daily live smoke test, or a manual run recorded in the PR: a stateless conversation that crosses a low `compactAt` compacts once in the background, and the next turn's input shrinks
- [ ] ADR-0029 accepted (or amended) with the implementation's evidence, and ADR-0003's status line updated
- [ ] Docs, minor changeset, snapshot regenerated
- [ ] `/security-review` and `/code-review` before merging
- [ ] `pnpm check` passes
