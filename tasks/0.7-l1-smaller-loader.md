# l1. A smaller loader

- **Status:** in progress (`perf/smaller-loader`)
- **Release:** 0.7 (base branch `release/0.7`)
- **Lane:** Loader
- **Touches hot files:** Yes (`embed/loader.ts`; nobody else changes it before l2)
- **Changes the public API or the protocol:** No
- **Depends on:** x4 (done)

## Goal

The loader shrinks from 5,052 B to about 4,648 B (gzipped) with the same behavior, by the changes in ADR-0033 decision 1, and its budget becomes 5,632 B (decision 2), so l2 fits. It also stops breaking on pages that enforce Trusted Types, and the stale loader sizes in the docs are corrected.

## Decisions to read first

- ADR-0033 and `spikes/s10-loader/FINDINGS.md` (x4), [ADR-0005](../docs/adr/0005-embedding-model.md), [ADR-0013](../docs/adr/0013-browser-events.md).
- `spikes/s10-loader/patches.mjs` has each change as a small patch: `css-file`, `surface-vars` with `surface-dedupe`, `no-style-fallback`, `icons`, `server-defaults`. Apply them by hand in that order; `node measure.mjs` in the spike gives the size after each.

## What changes

1. `STYLES` moves to `embed/loader.css`, imported with `?inline`. `vite.loader.config.ts` sets `build.cssTarget: ['chrome111', 'edge111', 'firefox121', 'safari16.4']` (without it, Lightning CSS expands `system-ui` into a long font list). Check that `tsconfig.browser.json` knows `*.css?inline` (a `declare module` if not).
2. `--bg` and `--fg` on `:host`, per scheme, replace the orb's and the panel's dark rules.
3. The `<style>` fallback goes.
4. The icons lose their no-op `fill` attributes.
5. `server/launcher.ts`: `loaderWithLook` always inlines a look, under the bot's ID or, with no bot, a default one under `''`. The loader takes `looks()[botId] ?? looks()['']` and drops its fallback colors and texts and the `look?.` checks. The default look must match what the loader's fallbacks give today. Unit tests that run the loader must inline a look.
6. **Trusted Types:** the launcher's icons are built with `createElementNS` (an `svg` with its `path`) instead of `innerHTML`. Today `icon.innerHTML = …` throws on a page with `require-trusted-types-for 'script'`, so the launcher never mounts there. Keep the `aria-hidden` icon, its size and its turn animation. The spike didn't measure this; give its cost in the pull request.
7. **The budget:** `LOADER_BUDGET_BYTES` in `scripts/inline-assets.mjs` becomes 5,632 (5.5 KB), with a comment pointing at ADR-0033.
8. **Stale sizes:**
   - `docs/support.md` says the loader is "about 3 KB": give the measured size and the 5.5 KB budget.
   - `ROADMAP.md` says 5,016 of 5,120 bytes (the 0.7 greeting item): give the new size and budget.
   - ADR-0018 records 5,016 B (twice). Those were true when it was written, so add a dated note pointing at ADR-0033 instead of rewriting them.

Not in scope: helpers for `createElement` and `setAttribute`, and shorter warnings (the spike rejected both).

## Definition of Done

- [ ] e2e on two origins passes unchanged; browser events unchanged
- [ ] Visual baselines rerun (Lightning CSS reorders declarations and rewrites colors); any diff explained
- [ ] A script tag with only `data-bot` still gets the default look
- [ ] e2e: the launcher mounts and opens the chat on a host page that sends `Content-Security-Policy: require-trusted-types-for 'script'`
- [ ] The budget in `inline-assets.mjs` is 5,632 B; `docs/support.md`, `ROADMAP.md` and ADR-0018 give the right sizes
- [ ] Loader size before and after in the pull request (expected about 4,648 B before the Trusted Types fix), with the fix's own cost
- [ ] Patch changeset
- [ ] `pnpm check` passes
