- **Status:** blocked (task 5, ADR-0020 accepted)

## Goal

The public surface matches what ADR-0006 and ADR-0020 list, and nothing resolved or internal is frozen into it before more add-ons depend on it.

## Decisions to read first

ADR-0006, ADR-0020, the `release` skill (public API snapshot).

## Files and area

As ADR-0020 decides; at the time of writing:
- `Bot` (with `Required<BotLimits>`) and `BotWidget` stop being exported from `.`. Users keep `BotDefinition`.
- `ERROR_CODES` and `ErrorCode` become importable from `.`, so code can switch on them.
- `PROTOCOL_VERSION` stays exported and is listed.
- `zod` becomes an optional peer. `defineTool` keeps requiring it, and a script-tag-only site installs nothing extra.
- Node 26 joins the support matrix and `engines` (after task C1 tested it).
- Deprecation warnings one minor earlier are not possible for type-only removals. Say so in the changeset and `docs/support.md`.

## Don't touch

Behaviour. This is surface only.
