## Goal

ADR-0032 (Proposed) extends [ADR-0016](../docs/adr/0016-admin.md) with what building it needs: the exact `AdminStore` port, how the console is served without reading files, and how deleting a conversation reaches the store. ADR-0016 is accepted and isn't rewritten; ADR-0032 says what it extends.

## What the ADR decides

- **The port:** methods for usage reports, ratings, transcripts, handoffs and leads (if stored at all), listing and aggregation queries for the dashboard, retention and delete by conversation. What is in the core and what is in `@boldare/askdare-admin`.
- **Delete:** `DELETE <basePath>/conversation` and a store's `sweep` call the `AdminStore`. Whether a sweep helper for OpenAI Files joins core here.
- **Stage 1 console:** a route served by the chat handler, off by default; its assets inlined at build time like the widget app (no file reads at runtime); access by secret or by an identity allowlist; headers (`no-store`, `frame-ancestors 'none'`).
- **Stage 2 add-on:** what `@boldare/askdare-admin` contains (UI, hook wiring) and how the app mounts it.
- **Budgets:** the console must not grow the loader or the React entry.
