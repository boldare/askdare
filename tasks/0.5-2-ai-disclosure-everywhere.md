# 2. The AI disclosure on every path

- **Status:** blocked (task 1)
- **Release:** 0.5
- **Lane:** Core
- **Touches hot files:** Yes (`react/headless.ts`)
- **Changes the public API or the protocol:** Yes: API snapshot, ADR-0019 and a minor changeset (a new primitive)
- **Depends on:** 1, ADR-0019 accepted

## Goal

Every way of building the chat can tell visitors they are talking to an AI (AI Act art. 50(1), in force since 2026-08-02), with the same configuration as today (`widget.disclosure`, `false` to hide it). Nothing is forced on the operator.

## What exists

The skin shows `disclosure.text` under the message field by default (`widget.disclosure`, `false` hides it; `docs/styling.md`). Sites that build their own UI with the headless primitives (ADR-0011) or `embedPath` (ADR-0018) can leave it out without noticing.

## Decisions to read first

ADR-0019, ADR-0004 (requirement 6), ADR-0011, ADR-0018.

## Files and area

- A `Disclosure` primitive in `@boldare/askdare/react`, using `bot.disclosure` and the texts. The default skin uses it.
- In development, `Root` notes once in the console when the chat rendered without a `Disclosure` and `disclosure` isn't `false`. `disclosure: false` silences it.
- `askdare doctor` mentions `disclosure: false` as information (not a failure) and names art. 50.
- Docs: `docs/react.md`, `docs/going-public.md`, and the "In 0.5, a `Disclosure` primitive…" sentence in `docs/compliance.md` section 1.

## Don't touch

The texts' wording in `i18n/texts.ts`. Task 5 owns that file during 0.5.
