# b1. Room in the React entry for 0.7

- **Status:** ready
- **Release:** 0.7 (base branch `release/0.7`)
- **Lane:** Hygiene
- **Touches hot files:** No (`react/*` and `chat/*` outside the hot files; not `react/headless.ts`)
- **Changes the public API or the protocol:** No
- **Depends on:** none

## Goal

`@boldare/askdare/react` has at least 1.5 KB of headroom under its 34 KB budget, without dropping a feature, so c2 (the "Reconnecting…" fix) and c4 (handoff and form UI) fit. ADR-0028 says the next feature that grows the entry makes room first; this is that step.

## Decisions to read first

- [ADR-0028](../docs/adr/0028-react-budget-34-kb.md), [ADR-0023](../docs/adr/0023-human-check-and-react-budget.md), [ADR-0011](../docs/adr/0011-react-api-and-inline-chat.md).
- The `vercel-react-best-practices` skill.

## Files and area

- `packages/askdare/scripts/react-size.mjs`: measure what each module costs (a temporary breakdown, not committed).
- Candidates: the Markdown renderer, skin components loaded only when used, shared helpers duplicated between `chat/` and `react/`.

## Don't touch

- `react/headless.ts`, `chat/state.ts`, `chat/reducer.ts`, `chat/store.ts`, `chat/events.ts` (c2). Visual output: visual baselines must not change.

## Definition of Done

- [ ] `react-size.mjs` shows the new sizes; numbers in the pull request
- [ ] Visual and e2e tests unchanged
- [ ] Patch changeset
- [ ] `pnpm check` passes
