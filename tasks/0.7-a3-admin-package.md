# a3. `@boldare/askdare-admin`: the dashboard (stage 2)

- **Status:** blocked (p2)
- **Release:** 0.7 (base branch `release/0.7`)
- **Lane:** Add-ons
- **Touches hot files:** No (a new package, `packages/askdare-admin/`)
- **Changes the public API or the protocol:** Yes: a new package, first release by hand (RELEASING.md section 5)
- **Depends on:** p2. Checked end to end after c5

## Goal

An owner mounts the dashboard in their Next.js app and sees cost per bot, day and model, ratings over time, 👎 answers with comments, and a review of a 👎 conversation from the stored transcript, as ADR-0016 stage 2 describes.

## Decisions to read first

- [ADR-0016](../docs/adr/0016-admin.md), ADR-0032, [ADR-0001](../docs/adr/0001-shape-and-packaging.md), [ADR-0006](../docs/adr/0006-support-matrix-and-versioning.md), [ADR-0004](../docs/adr/0004-threat-model.md).
- `packages/askdare-otel/` and `packages/askdare-postgres/`: package setup, build, `publint` and `attw`.

## Files and area

- `packages/askdare-admin/`: hooks that feed an `AdminStore` (`onUsage`, `onFeedback`, `onTranscript`, and handoffs and leads per ADR-0032), the dashboard pages and their server handlers, access checked on every request.
- No `openai` or `next` types in its `.d.ts`.
- A page in `site/` that mounts it with the memory store, for the e2e suite (e1).

## Don't touch

- `packages/askdare/` (c5 owns the core side). The other add-ons.
