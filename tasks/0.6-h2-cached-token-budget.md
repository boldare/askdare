# h2. Token budgets weigh cached input

- **Status:** in progress (`fix/cached-token-budget`)
- **Release:** 0.5.x patch (lands on `main`)
- **Lane:** Hygiene
- **Touches hot files:** No
- **Changes the public API or the protocol:** No. It changes what `dailyTokens`, `dailyTokensPerIp` and `globalDailyTokens` count: a patch changeset, docs and a line in ADR-0004.
- **Depends on:** none

## Goal

A long conversation with a warm prompt cache no longer runs out of the default token budgets long before it costs much. Budgets charge input read from the prompt cache at a tenth of a token, close to its price, so `dailyTokens` keeps working as a ceiling in money.

## Decisions to read first

- `spikes/s9-compaction/FINDINGS.md` (branch `claude/nice-shannon-75d6cf` until it merges): "For the parent session" and the 50-turn growth table. With the defaults, a realistic 50-turn conversation spends `dailyTokensPerIp` (200,000) by turn 12–13 and the bot's `dailyTokens` (2,000,000) by turn 33–37, while costing 0.31 USD.
- ADR-0004 (budgets in the threat model), ADR-0006 (public surface and 0.x versioning), ADR-0012 (`onUsage`).
- OpenAI's prompt caching guide: `cached_tokens` and `cache_write_tokens` are both part of `input_tokens`; reads cost 0.1× input on most current models (0.05× on some), writes 1.25× (30-minute lifetime) or 2.5× (12 hours).

## Files and area

- `packages/askdare/src/limits/limits.ts`: `settle` charges `inputTokens - cachedInputTokens + ceil(cachedInputTokens / 10) + outputTokens`. Missing or invalid cached counts are 0. The conversation's history size (`ask:ci`) stays in raw input tokens.
- `packages/askdare/src/limits/limits.test.ts`: unit tests, and a 50-turn conversation at 98 % cached input that keeps answering past turn 13.
- `docs/configuration.md`, `docs/costs.md`: what the budgets count, and the money ceiling.
- ADR-0004: one dated line under the token budgets.

## Don't touch

- `openai/stream-mapper.ts`: task h1 makes the usage details optional there.
- The reservation estimate in `beginTurn`: it stays at full weight, so the reservation remains an upper bound when the cache is cold.
- `onUsage` keeps raw tokens as OpenAI reports them (ADR-0012).
