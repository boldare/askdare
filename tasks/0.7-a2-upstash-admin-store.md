# a2. `AdminStore` on Upstash

- **Status:** blocked (p2)
- **Release:** 0.7 (base branch `release/0.7`)
- **Lane:** Add-ons
- **Touches hot files:** No (`packages/askdare-upstash/src/admin/`)
- **Changes the public API or the protocol:** Yes: a minor changeset for `@boldare/askdare-upstash`
- **Depends on:** p2

## Goal

`upstashAdminStore()` passes `adminStoreContract`, for sites with no SQL database. ADR-0032 shapes every query so it is answered from counters and lists kept at write time, so Redis needs no scans.

## Decisions to read first

- ADR-0032, [ADR-0016](../docs/adr/0016-admin.md).
- `packages/askdare-upstash/src/turn-log.ts` and its tests: the client, key prefixes and the `ASKDARE_TEST_UPSTASH` switch.

## Files and area

- `packages/askdare-upstash/src/admin/`, exported from the package.
- Retention through key TTLs plus `sweep()` (ADR-0032); no keys with raw visitor IDs or conversation content in their names.

## Don't touch

- `packages/askdare/`, `packages/askdare-upstash/src/turn-log.ts`.

- [ ] Contract suite passes against the local Redis behind the REST proxy, and once against Upstash (maintainer's key)
- [ ] Minor changeset
