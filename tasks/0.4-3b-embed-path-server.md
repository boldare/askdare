# 3b. `embedPath`: the bot option, the redirect, `getEmbedConfig`, `embedPageHeaders` and `doctor`

- **Status:** ready
- **Release:** 0.4
- **Lane:** Core
- **Touches hot files:** Yes (`bot/define-bot.ts`, the API snapshot and ADR-0006)
- **Changes the public API or the protocol:** Yes: API snapshot, ADR-0006 and a minor changeset
- **Depends on:** none

## Goal

A bot with `embedPath` sends the widget's iframe to a page of the app instead of the library's page, and the app has everything the server side offers to build that page safely: its configuration and its headers, checked by `doctor`. The page itself (`EmbedRoot`) is 3c.

## Decisions to read first

ADR-0018 (the whole of "Configuration", "Headers" and "`doctor`"), ADR-0005, ADR-0011 ("Security of a chat inside the page"), ADR-0004, ADR-0006

## Files and area

- `packages/askdare/src/bot/define-bot.ts`: `embedPath`, validated as ADR-0018 says (same-app path, not inside `basePath`; the handler checks `basePath`, which `defineBot` doesn't know).
- `packages/askdare/src/server/handler.ts`, `serveEmbed`: for a bot with `embedPath`, a `302` to it with only `lang` and `mode` kept and `Cache-Control: no-store`; `?gallery=` still renders the library's page.
- `packages/askdare/src/next/`: `getEmbedConfig({ bots, bot, searchParams })` next to `get-chat-config.ts`, reusing `publicConfig()`, adding the bot's `allowedOrigins` and the mode; `embedPageHeaders({ bots, bot })`, built from `embedContentSecurityPolicy`'s `frame-ancestors` part and the `Permissions-Policy` that `serveEmbed` sends today (share them, don't copy).
- `packages/askdare/src/cli/doctor.ts` (and the `/doctor` report if needed): the checks in ADR-0018, with fixes that name `embedPageHeaders`.
- `api/askdare.api.txt`, ADR-0006's list of the public surface, a minor changeset.

## Don't touch

- `embed/loader.ts`: ADR-0018 keeps the loader as it is.
- `packages/askdare/src/react/` and `widget-app/`: the page's client side is 3c.

## Definition of Done

- [ ] Unit tests: `embedPath` validation (absolute URL, `//`, `\`, query, fragment, inside `basePath`), the redirect (kept and dropped parameters, `no-store`, gallery untouched, bots without `embedPath` unchanged), `getEmbedConfig` (language from `lang`, mode, no secrets, unknown bot), `embedPageHeaders` (with and without voice, the allowlist), each `doctor` check passing and failing
- [ ] `docs/configuration.md` lists `embedPath`; `docs/cli.md` lists the new `doctor` checks
- [ ] Changeset (minor)
- [ ] `pnpm check` passes
