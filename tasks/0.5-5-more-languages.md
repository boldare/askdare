# 5. Built-in German, French, Spanish, Italian and Czech

- **Status:** in progress (`feat/more-languages`): dictionaries written and tested, waiting for native-speaker review
- **Release:** 0.5
- **Lane:** Core
- **Touches hot files:** Yes (`i18n/texts.ts`)
- **Changes the public API or the protocol:** Yes: API snapshot (new dictionaries) and a minor changeset
- **Depends on:** none

## Goal

A chat works in German, French, Spanish, Italian and Czech without the operator writing a dictionary.

## Decisions to read first

ADR-0014 (runtime language, `locale: 'auto'`), `docs/texts.md`.

## Files and area

- `packages/askdare/src/i18n/texts.ts`: dictionaries for de, fr, es, it, cs with every key of `en`. A test fails when a key is missing in any language.
- Each translation reviewed by a native speaker before release (note who in the pull request), including the disclosure text, which carries legal weight.
- `docs/texts.md` lists the languages.

## Don't touch

Keys and their meaning. Right-to-left layouts are a later release.

- [ ] Five dictionaries with a completeness test
- [ ] Native-speaker review noted
