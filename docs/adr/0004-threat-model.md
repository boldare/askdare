# ADR-0004: Threat model for a public, anonymous chatbot

- **Status:** Accepted. Detailed in [THREAT_MODEL.md](../../THREAT_MODEL.md) and [the going-public guide](../going-public.md).
- **Date:** 2026-10-29

## Context

v1 was effectively an open, paid proxy:
- No authentication or rate limits.
- The client could override `assistantId`.
- Uploads were unbounded.
- `GET /files/:id` exposed metadata for any file in the organization.
- CORS reflected any origin, and `postMessage` used `'*'`.

An anonymous public endpoint **cannot be made unforgeable**. A determined attacker can always use it as a rate-limited LLM proxy.

## Decision

Goal: **bound the damage** (dollars per day, requests per IP or visitor) and **prevent escalation** (IDOR, tool misuse, XSS, exfiltration). The controls map to OWASP Top 10 for LLM Applications 2025 entries LLM01, LLM02, LLM05, LLM06, LLM07 and LLM10.

- **Tokens:**
  - Two kinds, both HS256 with `typ`, `aud = botId`, `iss` and `kid`, verified with `algorithms: ['HS256']`:
    - access token: 15 minutes, kept in memory;
    - resume token: 30 days.
  - `CHAT_SECRET` must be at least 32 bytes, otherwise startup fails. Rotation via `CHAT_SECRET_PREVIOUS`.
  - `visitorId` is generated by the server.
- **The client never chooses** the model, instructions, tools, vector stores, raw `file_id` values or OpenAI conversation IDs. It only gets signed handles.
- **Limits:**
  - sessions per IP, messages per visitor per minute;
  - daily budgets per bot and global;
  - max input characters, `max_output_tokens`, max tool steps, max turns;
  - kill switch via an env var.
  - Counters live in memory by default; `@boldare/chatdock-upstash` shares them across instances.
- **Required deployment guidance:** a dedicated OpenAI project with a restricted key, a model allowlist and a **hard spend limit**. This is the backstop that needs no infrastructure.
- **Client IP:** `getClientIp(req)` with Vercel and Heroku presets plus `trustProxy`. The leftmost `X-Forwarded-For` value is spoofable.
- **Transport:** no cookies, Bearer tokens only (no CSRF), JSON-only POST bodies.
- **Origin:** a per-bot `frame-ancestors` allowlist with no `*` by default. Origin is a browser signal, not authentication.
- **Output and uploads:**
  - Markdown is sanitized with no raw HTML and with link and image allowlists.
  - Uploads are validated by magic bytes, SVG is rejected, and the default cap is 4 MB.
- **Abuse attribution:** `safety_identifier = hash(visitorId)`.
- **Logs** contain no message content or PII by default. Errors map to stable codes with no internals or stack traces.
- **Optional:**
  - a `HumanVerifier` port with a Cloudflare Turnstile adapter, checked at session creation only;
  - `identify()` with a separate `IDENTITY_SECRET` JWT issued by the host's backend (may slip to 0.2).

## Required before any public deployment, including demos

1. Session tokens, server-side ownership checks and signed attachment handles.
2. Limits and daily budgets, a kill switch, and token, step, turn and input caps.
3. A dedicated OpenAI project with a restricted key, a model allowlist, a hard spend limit and tested alerts.
4. A `frame-ancestors` allowlist with no `*`. No wildcard CORS. The client cannot select the model, instructions, tools or stores.
5. Sanitized markdown, plus upload type and size validation.
6. No content or PII in logs. A written retention decision, a privacy notice and an AI disclosure.
7. A random `CHAT_SECRET` of at least 32 bytes with documented rotation. Errors that don't leak internals.
