The orb launcher (Aura and Halo) shows its label beside the orb, on the panel's background, so visitors can tell it opens a chat. Set the text with `launcherLabel`; it defaults to "Ask us". A launcher with a visible label (orb or pill) now has an accessible name that starts with that label, as WCAG's "label in name" asks.
