# Integrations

Brightloop connects to the tools your team already uses. Integrations are set up by workspace admins in **Settings → Integrations**.

## Slack

Post task updates to a Slack channel and create tasks from a Slack message with the `/brightloop` command. Available on every plan.

## GitHub and GitLab

Link pull requests and merge requests to tasks by putting the task key (for example `BL-142`) in the branch name or the title. A task moves to **Done** automatically when the linked pull request is merged. Available on Team and Business.

## Calendars

Due dates sync one way to Google Calendar and Microsoft Outlook. Changes made in the calendar are not written back to Brightloop.

## Zapier and Make

More than 40 triggers and actions are available through Zapier and Make, including "task completed" and "comment added". Available on Team and Business.

## What we don't integrate with

There is no Jira two-way sync. You can import from Jira once with a CSV export (see the support page on importing data).
