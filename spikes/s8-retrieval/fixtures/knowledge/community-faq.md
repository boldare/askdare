# Community answers

These answers were written by Brightloop users in the community forum. They are not official.

## Can I export my tasks to Excel?

Yes, any project can be exported as CSV from the project menu (Export → CSV). Excel opens the file directly. — answered by user "marta_pm"

## Is there a desktop app?

No, there's no desktop app, but the web app can be installed as a progressive web app from Chrome or Edge. — answered by user "devops_dan"
