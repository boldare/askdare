Accessibility

The Brightloop web app aims to meet WCAG 2.2 at level AA. An independent audit took place in September 2026; the full report is available on request from support.

Keyboard shortcuts

  • C creates a task in the current project.
  • / opens search.
  • ? shows every shortcut.

Known issues

Drag and drop on the board has a keyboard alternative (the Move to… menu), but the timeline view cannot yet be used with a screen reader. A fix is planned for 2027.

Reduced motion

Brightloop follows the operating system's reduced-motion setting and turns off animations.
