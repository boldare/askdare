@AGENTS.md

This is the chatdock starter app: the e2e target, the scaffold source and the docs sample. Keep it minimal and in line with the root `CLAUDE.md`. The home page doubles as the Boldare-branded demo: one bot per theme (`DEMO_BOTS`), switched with `?theme=` and `?mode=bubble|inline`, and the chat script added after hydration (`app/chat-script.tsx`). `AGENTS.md` is generated by `next dev` (Next.js 16.3+); commit it when it changes.
