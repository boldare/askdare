@AGENTS.md

This is the askdare website (private, never published): the Boldare-branded demo on the home page, the state gallery (`/gallery`, behind `ASKDARE_GALLERY=1`) and the docs (`/docs`). It is the e2e and visual test target. The minimal template users start from is `examples/starter`; keep demo features out of it.

The home page has one bot per theme (`DEMO_BOTS`), switched with `?theme=` and `?mode=bubble|inline`, the chat script added after hydration (`app/chat-script.tsx`), a three.js ferrofluid shape per theme in the hero (`app/_shape/`, loaded on demand and only on large screens with a mouse: a sphere, cone, cylinder, cube or octahedron; phones and reduced motion get a still from `public/shapes/`, re-rendered with `node site/scripts/shape-stills.mjs` while `next dev` runs), the same shapes as flat icons in the theme cards (`app/shape-icon.tsx`), the theme and mode switches in a dock fixed to the bottom of the window, and BLDR as the custom-theme example (`defineTheme` + `widget.css` in `askdare.config.ts`). `AGENTS.md` is generated by `next dev` (Next.js 16.3+); commit it when it changes.

The docs (ADR-0010) render the repository's `docs/*.md` and ADRs at build time in `app/docs/`: `_lib/content.ts` reads, renders (unified, shiki, no raw HTML) and indexes them, and holds the sidebar (`NAV`; the build fails when a guide is missing from it). Links between guides become `/docs/<page>`, other links point to GitHub. Search uses `/docs/search.json`, built from the same files. The "askdare docs" chat (bot `docs`) shows only with `DOCS_VECTOR_STORE_ID`; `node site/scripts/docs-kb.mjs` syncs the docs to that store (costs OpenAI storage: run it on request only).
