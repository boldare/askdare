@AGENTS.md

This is the askdare website (private, never published): the Boldare-branded demo on the home page, the one-click deploy walkthrough (`/deploy`: a `CHAT_SECRET` made in the browser, never sent; the Vercel link in `app/deploy/clone-url.ts` is the same as in the README and docs), the state gallery (`/gallery`, behind `ASKDARE_GALLERY=1`) and the docs (`/docs`). It is the e2e and visual test target. The minimal template users start from is `examples/starter`; keep demo features out of it.

The home page has one bot per theme (`DEMO_BOTS`), switched with `?theme=` and `?mode=bubble|inline`, the chat script added after hydration (`app/chat-script.tsx`), a three.js ferrofluid shape per theme in the hero (`app/_shape/`, loaded on demand and only on large screens with a mouse: a sphere, cone, cylinder, cube or octahedron; phones and reduced motion get a still from `public/shapes/`, re-rendered with `node site/scripts/shape-stills.mjs` while `next dev` runs), the same shapes as flat icons in the theme cards (`app/shape-icon.tsx`), the theme and mode switches in a dock fixed to the bottom of the window, and BLDR as the custom-theme example (`defineTheme` + `widget.css` in `askdare.config.ts`). Every demo bot has the lead form and handoff (`forms.ts`, ADR-0030 and ADR-0031); `demo-hooks.ts` sends handoffs to a test webhook (`HANDOFF_WEBHOOK_URL`, an HTTPS receiver in `e2e/servers/webhook.mjs` for the e2e tests) or the log, and leads to the log, never to a person. With `ADMIN_SECRET` or `ADMIN_ALLOW`, the chat route serves the admin console at `/api/chat/admin` with the `@boldare/askdare-admin` dashboard (ADR-0032), on the memory admin store, or Upstash's when one is connected. `AGENTS.md` is generated by `next dev` (Next.js 16.3+); commit it when it changes.

The docs (ADR-0010) render the repository's `docs/*.md` and ADRs at build time in `app/(site)/docs/`: `_lib/content.ts` reads, renders (unified, shiki, no raw HTML) and indexes them, and holds the sidebar (`NAV`; the build fails when a guide is missing from it). Links between guides become `/docs/<page>`, other links point to GitHub. Search uses `/docs/search.json`, built from the same files. The "askdare docs" chat (bot `docs`) shows only with `DOCS_VECTOR_STORE_ID`; `node site/scripts/docs-kb.mjs` syncs the docs to that store (costs OpenAI storage: run it on request only).
